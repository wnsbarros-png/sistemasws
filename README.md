# Sistemas WS

Site institucional em HTML, CSS e JavaScript: https://sistemasws.com.

Apresenta ClippPro, ZWeb e Gfood e direciona contatos ao WhatsApp da Sistemas WS.

## Desenvolvimento

- `npm ci`: instala ferramentas de verificação.
- `npm run serve`: serve os arquivos em http://localhost:8080 com Python 3.
- `npm run check`: verifica o JavaScript, o layout responsivo, os links e regras de acessibilidade com Playwright/Chrome e axe-core.
- `WS_TEST_URL`: URL alternativa para testar uma prévia ou produção.
- `WS_CHROME_PATH`: caminho de um executável Chrome/Chromium alternativo.

As ferramentas de desenvolvimento não são necessárias para servir o site. Publique apenas os arquivos públicos no Cloudflare Pages, projeto `sistemas-ws`.

Leia `CONTINUAR.md` para a localização do projeto, decisões aprovadas, publicação e recuperação.
